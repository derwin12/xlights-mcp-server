# Claude memory notes

Copies of Claude Code's per-project memory from the Windows PC, so the same lessons and preferences are available on
other machines. `MEMORY.md` is the index; each other file holds one note.

To use them as live memory on another machine, copy the `.md` files into that machine's Claude Code project memory
folder (e.g. on macOS `~/.claude/projects/<encoded-project-path>/memory/`). Paths inside the notes (E:\, F:\) are
Windows drive letters from the PC.
