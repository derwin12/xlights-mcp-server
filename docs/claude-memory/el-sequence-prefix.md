Name sequences made from the EasyxLightsVideos YouTube channel (PRO Display videos) with an `EL_` prefix, e.g. `EL_Halloween Is Here v1`.

**Why:** User wants them grouped and distinguishable from other vendors' sequences (EL = EasyLight).
**How to apply:** Use the prefix in the `video_beams_to_xsq.py` name argument; keep a new name per revision. Todo list of 81 PRO videos: `test_videos/PRO_VIDEOS_TODO.md`. See [[video-beam-to-moving-head-project]].

Duplicate uploads on the channel: use the most recent one (user rule, 2026-10-04); only duplicate found: Lady Gaga "Killah" (older YG_3OOsA9hA has no audio, skipped).
